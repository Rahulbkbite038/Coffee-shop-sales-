# ☕ Coffee Shop Sales Dashboard

This repository contains an **Excel dashboard** analyzing sales data from multiple coffee shop locations. It uncovers patterns in order quantities, product performance, customer preferences, and location-wise revenue.

## 📁 What’s included

- `Coffee_Shop_Sales.xlsx` – The main Excel file with:
  - Raw data (Sheet1)
  - Pivot tables
  - Interactive dashboard (`Dashboard(sell)` sheet)

## 📊 Key insights from the dashboard

### ⏰ Quantity Ordered by Hour
Sales peak during morning (8–10 AM) and mid‑afternoon (2–4 PM).

### 🥧 Category‑wise Sales (%)
- **Flavours** lead with 38%  
- Bakery (27%)  
- Drinking Chocolate (10%)  
- Coffee itself is only 1% (likely sold as part of flavored drinks)

### 📏 Size Distribution
Small (32%), Large (30%), Regular (29%) – almost equal preference.

### 📍 Store Location Performance
- Hell’s Kitchen: **1,596 orders**  
- Astoria: 1,284  
- Lower Manhattan: 1,255

### 🏆 Top 5 Products by Sales
| Product           | Revenue (£) |
|------------------|-------------|
| Brewed Chai      | 5,937.49    |
| Barista Espresso | 2,499.15    |
| Baked Goods      | 2,005.85    |
| Hot Chocolate    | 1,871.00    |
| Other            | 1,856.75    |

### 📅 Weekday Order Volume
Tuesday (5,450) and Monday (5,415) are busiest – Thursday drops to 4,331.

### 💰 Overall Metrics
- **Total Sales**: £6,981,123.33  
- **Avg Bill/Person**: £149.12  
- **Avg Order/Person**: 4.68 items

## 🚀 How to use

1. Download `Coffee_Shop_Sales.xlsx`  
2. Open with Excel (2016 or later)  
3. Explore the `Dashboard(sell)` sheet – slicers and pivot charts are interactive

## 📌 Notes

- All currency is in GBP (£)  
- Data is anonymized / synthetic for portfolio use  
- Perfect for learning pivot tables, slicers, and dashboard design in Excel
